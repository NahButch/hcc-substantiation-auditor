# HCC Substantiation Auditor

A tool for auditing the clinical substantiation of HCC (Hierarchical Condition
Category) diagnosis codes used in risk-adjustment, in support of RADV
(Risk Adjustment Data Validation) review workflows.

## Status

Early development.

## Structure

Development happens across parallel worktrees:

- `feature/agent` — the auditing agent
- `feature/harness` — the evaluation / execution harness
